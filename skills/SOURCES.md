# Curated skill sources

These 20 portable, instruction-only profiles were reviewed and adapted for the
Qwen Harness toolset from the public [OpenAI Skills repository](https://github.com/openai/skills), pinned to its `main` branch on 2026-08-25. No source scripts, binaries, credentials, network installers, or auto-execution hooks are bundled. Each skill can only be activated explicitly with its leading slash command.
